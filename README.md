# VPS & Cloud Provider Research

Public research workspace for comparing VPS, VDS, cloud VM, regional cloud, managed Kubernetes, and related infrastructure providers worldwide.

## Goals

- Build a broad, deduplicated provider catalog.
- Track 8 GB, 16 GB, and larger compute plans with comparable fields.
- Compare CPU allocation, RAM, NVMe/storage, traffic, network speed, IPv4/IPv6, private networking, API/Terraform support, billing model, backups, and Kubernetes capabilities.
- Separate bargain VPS, dedicated-resource VDS, regional cloud, elastic cloud, and managed Kubernetes instead of mixing them into one ranking.
- Record sources and verification dates so prices and availability can be rechecked.

## Public-repository rules

- Do not store credentials, tokens, private infrastructure details, customer data, or confidential project information.
- Keep provider notes generic and source-based.
- Treat aggregator data as discovery-only until verified against an official source.

## Status

Initial repository setup. Provider discovery and normalization work will be developed on dedicated research branches.
